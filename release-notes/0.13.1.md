# MachBoost 0.13.1

MachBoost 0.13.1 fixes desktop upgrades when an older resident daemon is still
using the local server port.

## Fixed

- The macOS app now reads the running daemon version before reusing it.
- A newer app gracefully shuts down and replaces an older local MachBoost
  daemon, preventing new UI features from talking to stale API routes.
- Equal-version and newer daemons remain resident instead of being restarted.
- Added native regression coverage for daemon version detection and ordering.

## Included from 0.13.0

- Native desktop team inference with scoped host connections.
- Local repository coding tools with explicit write approval.
- Host-side client activity, model requests, and resident MLX model controls.
- The responsive team coding architecture guide on the project website.

This is an ad-hoc signed Apple Silicon community build. It includes its own
Python 3.13 and MLX runtime and does not require a separate Python installation.
