# MachBoost 0.15.0

This release focuses on native app reliability and a simpler shared-inference workflow.

## Highlights

- Replaces the Local/Host pool prerequisite flow with a direct Connections screen: nearby devices are visible immediately, connecting asks only for the host key, and manual addresses remain under an advanced disclosure.
- Keeps the active reasoning disclosure open while it streams, closes it when the next content or tool event starts, and preserves chronological reasoning, tool, and answer blocks.
- Filters Muse Glimmer's verbatim user-prompt echo from the beginning of reasoning streams and removes protocol-only whitespace before visible answers.
- Prevents repeated identical repository tool calls from re-running, then requests a tool-free final answer instead of failing at the tool-round limit.
- Repairs invalid persisted context controls and runs automatic conversation summaries with the fastest supported reasoning level.
- Shows model-download state immediately during compatibility checks and reports file, byte, and percentage progress in Models and the chat model picker.
- Enables EdDSA-verified Sparkle updates for community builds, including in-app checks, installation, and relaunch without an Apple Developer subscription.

The community DMG remains ad-hoc signed and is not Apple-notarized. A first install downloaded through a browser may still require **System Settings → Privacy & Security → Open Anyway**.
