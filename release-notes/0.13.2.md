# MachBoost 0.13.2

This release fixes native coding tool calls and makes repository work visible and reviewable in the macOS app.

## Coding agent reliability

- Parse Muse Glimmer's native attribute-style tool syntax as structured calls instead of displaying control tokens in chat.
- Continue supporting canonical JSON tool tags, multiple calls in one response, and visible text surrounding tool requests.
- Execute multiple repository reads in a round and continue model-to-tool-to-model exchanges for up to eight rounds.
- Persist queued, running, completed, denied, and failed tool activity when a conversation is reopened.

## Native app experience

- Replace raw tool arguments with collapsible, human-readable activity rows.
- Show bounded tool results for repository listings, reads, and searches.
- Record a patch preview for approved file edits and creations.
- Add a Code Changes control with patch review, Open File, and Reveal in Finder actions.
- Keep write approval required before any repository mutation.

## Validation

- 449 Python tests passed.
- All Go package tests passed.
- 37 Swift unit tests passed.
- 18 native macOS UI tests passed, including a three-call, multi-round coding workflow with an approved edit.

The downloadable community DMG remains ad-hoc signed. macOS may require Control-clicking the app and choosing Open until a Developer ID-notarized release is available.
