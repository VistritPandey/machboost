# MachBoost 0.12.1

MachBoost 0.12.1 fixes native model downloads in the macOS app when the
bundled Hugging Face runtime uses a disabled `tqdm` progress bar.

## Fixed

- Prevented model pulls from failing with
  `'MachBoostDownloadProgress' object has no attribute 'desc'`.
- Preserved file names, byte totals, completed-byte counts, and cancellation
  while model downloads stream progress to the app.

Users of 0.12.0 should install this update before downloading a new MLX model.
