# MachBoost 0.16.5

This patch restores standalone CLI access to an authenticated local macOS app
daemon.

- Reads the active community app credential from its owner-only Application
  Support store when the installed app is ad-hoc signed.
- Continues using macOS Keychain for Developer ID signed app builds.
- Rejects community credential files that are not owned by the current user or
  are readable by other users.
- Uses the same credential resolution for normal CLI requests and Claude
  Desktop launch configuration.
- Preserves bearer authentication for LAN clients.

This fixes `machboost run`, `machboost ps`, and related localhost commands
returning `authentication required` while the native app server is running.
