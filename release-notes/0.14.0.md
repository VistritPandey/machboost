# MachBoost 0.14.0

This release makes native coding chat responsive and adds the first multi-host inference pool to the macOS app.

## Chat and coding

- Streams tool-enabled responses immediately while withholding raw Muse Glimmer and XML tool protocol.
- Preserves the actual event order across reasoning, visible prose, multiple tool calls, tool results, and follow-up rounds.
- Inserts tool rows as their stream events arrive, then updates the same rows through queued, running, succeeded, denied, or failed states.
- Keeps reasoning off by default for ordinary chat; supported models can enable it from Generation controls.
- Reports total model-token throughput from backend decode timing, including reasoning and tool protocol, instead of deriving a misleading rate from visible text or full request time.

## Host pool

- Discovers nearby MachBoost servers with Bonjour and supports multiple authenticated endpoint/key profiles in Connections.
- Shows host availability, compatible models, residency, active requests, and queue depth inside the app.
- Routes each new request to a compatible host using model residency, observed latency, queue pressure, and immediate in-flight reservations.
- Allows the employee Mac to join the pool when it has the selected model ready.
- Maintains presence heartbeats and routes cancellation back to the host that owns the request.

Host selection occurs before generation. MachBoost does not migrate an active stream, combine unified memory across Macs, or load a missing model automatically. Automatic pool routing is currently provided by the desktop app; generic API clients continue to use the endpoint they target.

## Validation

- 457 Python tests, all Go package tests, 44 Swift/Xcode unit tests, and 18 macOS UI workflows pass.
- UI automation verifies chronological reasoning, tool, and final-response layout as well as multi-round coding, approval, and workspace-diff review.
- A warm Qwen2.5 3B source-runtime check measured approximately 0.14-0.17 seconds to first text and about 123-125 total model tokens per decode second for short plain and tool-enabled requests on the test Mac. These figures are responsiveness diagnostics, not universal model-speed claims.
