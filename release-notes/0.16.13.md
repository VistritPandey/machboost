# MachBoost 0.16.13

## Fixed

- Show token counts and fractional percentages instead of rounding small context
  usage to zero. Include enabled instructions, tool definitions, and text
  attachment sizes in the estimate; show reported input tokens separately.
- Allow manual summaries of short conversations. Check the automatic threshold
  before the next request as well as after replies, without requiring eight
  newer messages to remain unsummarized.
- Give summaries a separate output budget, disable optional reasoning correctly,
  and reconcile final server text instead of losing buffered output.
- Report empty, incomplete, and token-limited summaries without replacing saved
  context. Cancelling a summary no longer marks a completed reply as cancelled.
- Keep original chat history and expose the saved summary for inspection. Editing
  a summarized turn clears its stale summary before resending.
- Redact common bearer tokens, API keys, passwords, and provider-key prefixes
  before summary inference and again before local persistence.
- Replace generation steppers with editable numeric fields. Maximum output
  tokens is uncapped by default, the summary threshold can be typed directly,
  and Reset All to Defaults restores the complete generation panel.

Context percentages remain estimates, not exact tokenizer measurements. Model
summaries may omit details, and image-token usage is not included in the estimate.
