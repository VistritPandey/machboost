# MachBoost 0.15.3

MachBoost 0.15.3 fixes authentication between the native app and local CLI
clients. When the app protects its localhost server with a generated bearer
token, CLI and streaming requests now recover that existing token from macOS
Keychain after an authentication challenge and retry once.

The retry is restricted to loopback endpoints. Shared and remote hosts still
require an explicit or saved connection key, and credentials are never placed
in command arguments, logs, or connection files.

This patch includes the 0.15.2 device routing, connected-client visibility,
prefill diagnostics, developer-prefix warming, and Claude Desktop loopback
bridge improvements.
