# MachBoost 0.16.0

MachBoost 0.16.0 adds local MCP connectors and reusable skills to the native
macOS app, CLI, Python package, and authenticated server API. Users can connect
stdio or Streamable HTTP MCP servers, inspect their tools, and call them through
the same resident inference service used by chat and coding sessions. Connector
secrets are redacted from listings and stored only in the local extension
database.

The native app now exposes per-chat Tools and Repo Context controls. Tool calls,
reasoning, and visible responses remain ordered in the conversation timeline.
Skills provide reusable system instructions without changing model weights.

This release also fixes partial streamed responses. MachBoost now compares the
stream against the final authoritative token decode for plain and tool-enabled
chats, allowing clients to repair a missing prefix instead of saving truncated
text. Prefix-cache and generation metrics distinguish warm follow-ups from
requests that must process a changed tool schema or conversation prefix.

Additional changes include extension-management APIs, MCP CLI commands, model
stream reconciliation tests, local runtime immutability checks, and updated
documentation for the extension workflow.
