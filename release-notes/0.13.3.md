# MachBoost 0.13.3

This release repairs native Muse Glimmer coding sessions and adds a focused developer workspace to the macOS app.

## Changes

- Passes tool definitions through the native MLX-VLM chat template and parses Muse Glimmer's ATEM function-call format.
- Rejects malformed tool names and removes model control markers from visible and follow-up chat content.
- Adds Auto, Manual, Accept edits, Plan, and Bypass permissions modes with different repository-write policies.
- Adds a workspace-wide Git changes panel with branch status, file totals, expandable diffs, open, and reveal actions.
- Keeps per-message tool activity and patch review alongside the final working-tree view.
- Aggregates generated tokens and decode time across every tool round so chat throughput reflects the complete assistant turn.
- Hides malformed tool rows saved by older builds while preserving valid failed-tool diagnostics.
- Moves Keychain access off the main thread so stale community-build credentials cannot block app startup.

Repository tools remain confined to the user-selected workspace. Bypass mode removes approval prompts; it does not remove that filesystem boundary.
