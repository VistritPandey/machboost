# MachBoost 0.15.1

MachBoost 0.15.1 improves shared inference routing and response latency across
the native macOS app, Python package, and command-line interface.

## Highlights

- Automatically ranks local and saved MachBoost hosts using network latency,
  model residency, replica capacity, active requests, queue depth, and recent
  failures.
- Routes CLI and native app requests to the estimated fastest compatible host,
  with failover before streaming begins.
- Adds live host rankings to Connections, `machboost connections --probe`, and
  the interactive `/route` command.
- Reuses stable system, tool, and repository prompt prefixes for substantially
  lower first-token latency on follow-up requests.
- Separates Ollama socket draining from client rendering so a slow UI or API
  consumer does not stall upstream decoding.

Unique prompts still run at the selected backend's native inference speed;
prefix-cache gains apply when requests share stable leading context.
