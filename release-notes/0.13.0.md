# MachBoost 0.13.0

MachBoost 0.13.0 adds native desktop team inference. A Mac with sufficient
memory can host resident MLX models while other MachBoost apps use the same
chat and coding interface over the private network.

## Team inference

- Connect the desktop app to a MachBoost team host with a scoped API key.
- Discover only the native MLX models installed and permitted by that host.
- Request an additional model from the host administrator when it is absent.
- Keep repository access on each developer Mac. Bounded tool calls read,
  search, create, and edit files locally; only selected context and tool
  results are sent to the inference host.
- Report privacy-preserving device presence and request activity so the host
  can inspect connected clients without receiving local repository paths.
- Continue using OpenAI- and Ollama-compatible endpoints for existing agents.

## Host administration

- Inspect online clients and pending model requests in the Server view.
- Approve or dismiss model requests and download approved models on the host.
- Track desktop clients through authenticated team gateway APIs and stable
  Python client helpers.

## Documentation and validation

- Added a responsive architecture diagram to the project website.
- Expanded the team gateway and desktop documentation with the local-tool,
  remote-inference trust boundary.
- Added Python, Swift unit, and Swift UI coverage for enrollment, presence,
  model requests, inference switching, and repository tool execution.

MachBoost does not upload a repository or claim to accelerate every unique
prompt. Reuse improvements depend on genuine prompt, workspace, or media
overlap; native MLX serving and resident models provide the baseline runtime.
