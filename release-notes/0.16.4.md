# MachBoost 0.16.4

This release makes large model downloads observable and removable.

- Shows active model downloads in a persistent Models section instead of tying
  their status to the current search result.
- Aggregates concurrent Hugging Face/Xet shards into total bytes, completed
  files, transfer rate, ETA, and active shard names.
- Keeps cancellation available while several shards are downloading and blocks
  deletion until the matching transfer has stopped.
- Adds destructive model deletion to the macOS app with disk-size guidance and
  automatic resident-model unloading.
- Adds `machboost rm MODEL --weights` for explicit managed-cache removal while
  preserving alias-only behavior for plain `machboost rm`.
- Supports the same opt-in deletion lifecycle for native HF/MLX and
  Ollama-backed models.

MachBoost removes only model directories inside its configured Hugging Face or
Ollama cache. User-selected local model directories are never deleted.
