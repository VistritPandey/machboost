# MachBoost 0.9.0

MachBoost 0.9.0 adds revision-aware team memory, deterministic exact-request
reuse, budgeted OpenAI-compatible provider fallback, and a broader Ollama-style
model workflow.

## Team Memory

- Private employee and administrator-published team scopes.
- Workspace, principal, repository-revision, and dependency-digest isolation.
- Bounded local retrieval with stale-record rejection and redacted summaries.
- Opt-in exact reuse for deterministic, non-streaming text requests.
- Machine-readable avoided-token, avoided-cost, hit, miss, and namespace metrics.
- A deterministic five-developer benchmark covering shared retrieval, private
  isolation, workspace isolation, revision invalidation, and exact reuse.

## Provider Fallback

- OpenAI-compatible HTTPS provider registration with model allowlists.
- `local_only`, `local_first`, `external_first`, and `external_only` routing.
- Transient-only fallback, monthly budgets, token usage, and estimated cost.
- Provider secrets remain in environment/process memory or macOS Keychain and
  are never persisted in the team database.
- OpenAI SSE compatibility for routed requests, with buffered upstream delivery
  disclosed in response metadata.

## Ollama Compatibility

- Persistent model aliases through `/api/create`, `/api/copy`, and `/api/delete`
  plus `machboost create`, `machboost cp`, and `machboost rm`.
- Tokenizer-enforced context limits and Ollama-style sampling, penalty, stop,
  template, system, thinking, and structured-output options.
- Resident embeddings through `/api/embed`, `/api/embeddings`, and
  `/v1/embeddings`.
- Alias-aware load, show, stop, unload, and delete behavior.
- Empty chat/generate requests support explicit model load and unload lifecycle.

MachBoost still does not build arbitrary GGUF Modelfiles or push weights to the
Ollama registry. Its acceleration remains workload-specific: unique cold prompts
normally use native generation, and team-memory accounting is not a model decode
speed measurement.

## Native macOS App

- New **Server → Memory & fallback** controls for memory, reuse metrics,
  providers, budgets, and Keychain-backed credentials.
- The UI-test runner now disables hardened runtime only for XCTest injection;
  the application and release archives retain hardened runtime.
