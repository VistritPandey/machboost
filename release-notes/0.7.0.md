# MachBoost 0.7.0

MachBoost 0.7.0 is the first native macOS community preview. It combines a
SwiftUI chat app, a bundled Python/MLX runtime, concurrent local serving, and
context-specific acceleration paths in one Apple Silicon download.

## Highlights

- Native SwiftUI chat with streaming, stop, regenerate, local history, model
  management, persistent attachments, performance statistics, and menu-bar
  controls.
- Bundled relocatable CPython 3.13 runtime with MachBoost, MLX, `mlx-lm`, and
  `mlx-vlm`; no separate Homebrew or Python installation is required.
- Repository workspaces that index tracked source, retrieve focused evidence,
  return citations, and reuse compatible exact MLX prompt state on later
  questions.
- Concurrent resident-model gateway with bounded queues, cancellation,
  keep-alive controls, metrics, and OpenAI- and Ollama-compatible endpoints.
- Text and vision model catalog, architecture preflight, download progress, and
  explicit rejection of unsupported model/input combinations.

## Measured Results

On the recorded Apple Silicon workspace benchmark:

- Qwen2.5 3B repository workload: `3.02x` median, `6/6` exact token pairs.
- Qwen2.5 7B repository workload: `3.28x` median, `6/6` exact token pairs.
- Five different later repository questions: `2.97x` at 3B and `3.23x` at 7B.
- Repeated-image matrix: `13.51x` median of six Qwen model-level medians across
  72 paired requests, with every expected answer correct.
- Qwen3-VL first-view control without a reusable prefix: `0.99x`.

These results apply to exact reusable context. MachBoost does not claim faster
first requests, new images, unrelated prompts, or universal decode throughput.
Benchmark JSON and the research paper are included in the repository.

## Install

1. Download `MachBoost-0.7.0-arm64.dmg`.
2. Drag MachBoost into Applications.
3. Attempt to open MachBoost once.
4. Open **System Settings → Privacy & Security** and choose **Open Anyway**.

This free community build is ad-hoc signed and is not Apple-notarized. macOS
therefore requires the one-time manual approval above. Verify the accompanying
SHA-256 checksum before overriding Gatekeeper.

## Requirements

- Apple Silicon Mac
- macOS 14 or newer
- Sufficient disk space for the application and selected Hugging Face model
  weights

Model weights are downloaded only after confirmation and remain in the standard
local MachBoost/Hugging Face cache.
