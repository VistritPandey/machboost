# MachBoost 0.16.11

This patch keeps the desktop app usable when a saved inference host goes
offline.

## Changes

- Stops offline Team hosts from presenting a blocking startup alert.
- Uses a ready model on this Mac when no eligible remote host is reachable,
  even when local backup was disabled for normal pool routing.
- Continues to honor the local-backup preference while a compatible remote
  host is online.
- Keeps saved remote hosts available for automatic reconnection.
- Shows `This Mac (remote offline)` and the local catalog while emergency
  fallback is active.

## Validation

- 73 native Swift unit tests pass.
- The installed Release app at `/Applications/MachBoost.app` was tested with a
  saved offline host and local backup disabled.
- Muse Glimmer 30B loaded through the bundled MLX-VLM runtime, New Chat opened
  without an alert, and a streamed local response completed at 2.42 seconds
  time to first token.
