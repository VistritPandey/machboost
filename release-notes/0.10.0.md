# MachBoost 0.10.0

MachBoost 0.10.0 adds an opt-in fresh-prompt decode path for selected Qwen
models. DFlash block-diffusion drafting now runs behind the resident MachBoost
server and its existing OpenAI- and Ollama-compatible endpoints.

## Accelerated model aliases

- `qwen3.5:4b-dflash` selects a Qwen3.5 4B BF16 target and its published DFlash
  draft without requiring custom request fields.
- `qwen3.5:9b-dflash` is available for experiments but is not recommended as an
  equivalent native replacement yet.
- `machboost pull` downloads both target and draft repositories and reports
  cancellable progress for each component.
- `/api/catalog` reports DFlash capabilities, runtime support, memory guidance,
  and complete-pair cache state.

## Decode audit

`machboost bench-decode` compares native MLX and DFlash using the same target
weights. It now validates bounded greedy outputs, records token hashes and the
first mismatch position, and exits nonzero when accelerated output differs from
native MLX. Use `--validation-tokens 0` only for an intentional non-equivalent
throughput diagnostic.

On an Apple M5 Pro with the shippable `dflash-mlx==0.1.8` wheel, Qwen3.5 4B BF16
improved from 29.36 to 48.52 decode tokens/s across three fresh 512-token prompt
families. The median speedup was 1.649x, with per-family medians from 1.309x to
2.431x. All three 128-token validation prefixes matched native greedy output.

A same-weight Qwen3.5 9B BF16 audit improved from 16.55 to 26.44 tokens/s,
a 1.607x median. Two of three validation prefixes matched; the code row first
diverged at generated token 65. The 9B alias therefore remains experimental.

A Qwen3.5 9B 4-bit control improved from 54.63 to 68.32 tokens/s with adaptive
verification, a 1.318x median, but strict output validation found divergence.
Fixed 16-token verification regressed to 0.842x overall. The 9B path therefore
remains experimental.

These are decode-throughput results, not universal end-to-end, short-answer, or
quality-equivalence claims. BF16 targets also use more disk and unified memory
than the ordinary 4-bit aliases.

## Install

```sh
python3 -m pip install --upgrade "machboost[dflash]"
machboost pull qwen3.5:4b-dflash
machboost run qwen3.5:4b-dflash --show-stats
```
