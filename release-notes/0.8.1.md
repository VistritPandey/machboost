# MachBoost 0.8.1

MachBoost 0.8.1 corrects update handling in unsigned community builds of the
native macOS app.

## Fixed

- Unresolved `$(SPARKLE_PUBLIC_ED_KEY)` build placeholders are no longer
  mistaken for valid Sparkle signing keys.
- Community builds no longer request a missing signed appcast or show the
  generic "An error occurred in retrieving update information" dialog.
- Settings and the application menu now use **View Latest Release** for
  community builds. This opens the current GitHub Release for manual download.
- Automatic update controls are enabled only when the app contains a valid
  32-byte Sparkle public key.

## Installation

Existing `0.8.0` community installations cannot install this patch through
Sparkle. Download `MachBoost-0.8.1-arm64.dmg`, replace the copy in Applications,
and approve it again in System Settings if macOS requests confirmation.

The community DMG remains ad-hoc signed and is not Apple-notarized. Verify the
published SHA-256 checksum before overriding Gatekeeper.
