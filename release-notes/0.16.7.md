# MachBoost 0.16.7

This release makes command-line chat easier to read and fixes two Muse Glimmer
streaming failures.

- Adds a responsive, green-accented terminal chat layout with clear user,
  answer, reasoning, tool, host, and compact performance rows.
- Keeps redirected output plain and honors `NO_COLOR` for accessible terminals.
- Prevents abbreviated Muse role markers from appearing in answers or consuming
  the first word of a streamed response.
- Keeps the MLX-VLM thinking-budget controller active across cached follow-up
  turns, preventing default Muse reasoning from consuming the entire response
  budget without a visible answer.
- Preserves automatic routing from `--backend mlx` to MLX-VLM for Muse Glimmer.
