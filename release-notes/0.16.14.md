# MachBoost 0.16.14

## Fixed

- Report the actual inference destination separately from remote connection
  health. When a saved host cannot be used, the app now shows `This Mac` and an
  explicit local-fallback status instead of `This Mac (remote offline)`.
- Distinguish an invalid or missing remote API key from a device that is truly
  unreachable. The Connections view offers a direct Sign in action when the
  host is reachable but authentication must be refreshed.
- Migrate credentials saved by earlier ad-hoc builds from macOS Keychain into
  the protected community credential store. Existing secrets in the community
  store remain authoritative.
- Count only currently reachable remote devices in the inference-pool label.
