# MachBoost 0.16.6

This patch fixes native Muse Glimmer launches that explicitly select the MLX
backend. Full vision repository IDs now resolve to MLX-VLM just like MachBoost
model aliases, avoiding the text-loader `Model type muse_glimmer not supported`
failure.

The `machboost[mlx]` installation extra now includes a Muse-capable MLX-VLM
runtime, so one MLX install supports both text and vision repositories.

Muse chat and completion requests now use a bounded low-reasoning budget by
default. This prevents short CLI generations from ending before the model emits
its visible answer; explicit reasoning levels still override the default.
