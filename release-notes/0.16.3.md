# MachBoost 0.16.3

This release fixes latency and response integrity in native and third-party coding clients.

- Preserves one native prefix-cache lane across every tool round in a chat.
- Compacts Claude Code's repeated harness and tool schemas before local inference,
  even when a proxy rewrites the client User-Agent.
- Answers Claude's session-title helper locally so it never blocks a model replica.
- Flushes final tokenizer fragments across Anthropic, OpenAI, and Responses streams.
- Fixes duplicated characters in model search fields.
- Adds live Hugging Face MLX model discovery with preflight verification before download.

Measured on the captured Claude Code request used to reproduce the issue, with
Muse Glimmer 30B already resident, first model output improved from 235.6 seconds
to 9.42 seconds for a fresh session and 1.35 seconds after its session prefix was
warm. Visible answer text arrived at 12.01 and 3.95 seconds respectively because
the model reasoned before answering. Results depend on prompt size, model, memory
pressure, reasoning length, and cache reuse.
