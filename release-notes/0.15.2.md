# MachBoost 0.15.2

MachBoost 0.15.2 improves first-token latency diagnostics, per-chat device
routing, shared-host visibility, and Claude Desktop connectivity.

## Highlights

- Lets each app conversation choose Automatic, This Mac, or a named inference
  device while retaining safe pre-stream fallback.
- Records the device that served each response and separates model load, queue,
  prompt prefill, cached-prefix, and decode metrics.
- Primes the stable Developer-mode system and tool prefix before the first user
  message. In a local Muse Glimmer 30B test with a 2,204-token coding prefix,
  resident TTFT fell from 18.07 seconds before prefix reuse to 0.62 seconds
  after reuse. Novel prefixes still pay normal prefill cost.
- Shows clients currently connected to a shared MachBoost host, including their
  recent request counts and active model/workspace metadata.
- Adds a private authenticated localhost bridge for Claude Desktop when the
  selected shared host uses LAN HTTP, satisfying Claude's remote HTTPS rule
  without exposing the shared-host credential in Claude's profile.
- Makes reasoning, tool activity, and workspace-file rows clickable across
  their full width instead of requiring a precise chevron click.

The release preserves output generation behavior. Prefix warming changes when
stable prompt work is performed; it does not skip novel user content or claim a
decode-throughput increase.
