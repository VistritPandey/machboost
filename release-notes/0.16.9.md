# MachBoost 0.16.9

This release repairs reasoning and tool capability detection for native local
models, including repositories that do not have a built-in MachBoost alias.

## Changes

- Reads each cached repository's model config, tokenizer response schema, and
  chat template to detect text, vision, reasoning, tool, and context-window
  capabilities.
- Applies the same metadata path to compatible Qwen 3.x, DeepSeek, Muse
  Glimmer, and other locally cached MLX repositories instead of relying on a
  fixed model-name list.
- Parses Muse Glimmer's `to=self` reasoning protocol from its tokenizer schema,
  keeping reasoning separate from the visible answer without leaking protocol
  markers.
- Reconciles streamed text with the complete token decode so a missing first
  stream segment does not truncate the persisted answer.
- Shows reasoning events in both resident and direct terminal chat when the
  model emits them, including reasoning-native models that enable the channel
  through their own template.
- Suppresses an initial prompt echo when the model repeats it with minor article
  differences before beginning useful reasoning.

## Validation

- 591 Python tests pass.
- 71 Swift unit tests pass.
- 20 native macOS UI tests pass, including Muse reasoning/tool rendering,
  multi-round coding, model search, and model download progress.
- A live native Muse Glimmer 30B 4-bit coding run loaded in 4.48 seconds, called
  `list_files`, consumed the tool result, and returned the expected workspace
  entries. Its post-tool model turn measured 2.50 seconds TTFT and 17.2
  tokens/second on the development Mac.

These measurements describe one machine and prompt. They do not imply the same
latency or throughput for every model, context length, or host.
