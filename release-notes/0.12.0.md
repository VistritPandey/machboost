# MachBoost 0.12.0

MachBoost 0.12.0 expands the native macOS app into a coding-agent and team
gateway, improves long-chat usability, and moves Muse Glimmer to its native
Hugging Face MLX-VLM conversions.

## Native App

- Replaces the compact model picker with a searchable native-MLX browser that
  shows readiness, load state, capabilities, context size, disk size, and
  memory guidance.
- Adds automatic conversation compaction at a configurable 70-95% context
  threshold, plus a manual **Summarize Now** action. Recent turns remain intact
  after earlier context is summarized.
- Adds a visible Updates section with automatic-check status, **Check Now**,
  last-check time, and a download action when a newer community release exists.
- Adds native-model loading and coding-agent connection examples to the Server
  view.

## Coding And Team Gateway

- Adds streaming and non-streaming OpenAI Responses at `POST /v1/responses`.
- Adds streaming and non-streaming Anthropic Messages at `POST /v1/messages`.
- Preserves request IDs, cancellation, images, reasoning, function tools, team
  authentication, fair admission, workspace retrieval, and memory namespaces
  across the new protocol routes.
- Adds copyable Codex-style Responses and Claude Code connection settings.

## Native Muse Glimmer

- `muse-glimmer:30b` now resolves to
  `mlx-community/Muse-Glimmer-30B-4bit` through MLX-VLM 0.6.13.
- Adds explicit aliases for 5-bit, 6-bit, 8-bit, BF16, MXFP4, MXFP8, and NVFP4
  Hugging Face conversions.
- Keeps `muse-glimmer:30b-mlx` only as the explicit legacy Ollama bridge.
- Rejects partial Hugging Face snapshots that do not contain every indexed
  weight shard instead of showing them as runnable.

## Evidence

On an Apple M5 Pro with 48 GB unified memory, a same-loaded-model Qwen2.5 3B
audit over ten repository questions measured 3.501 seconds natively and 1.186
seconds with reusable MLX prefix state: `2.894x` median with 10/10 exact token
pairs. A separate ten-client diagnostic reached `5.06x` throughput, but only
16/20 outputs matched the uncached control; it is not an exactness claim.

The unsigned community DMG still requires **Open Anyway** approval in macOS
Privacy & Security. Apple-notarized distribution requires a paid Developer ID.
