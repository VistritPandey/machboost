# MachBoost 0.8.2

MachBoost 0.8.2 improves native chat readability, resident-model controls, and
authenticated serving for other computers on a private network.

## Native App

- Assistant messages now use the available conversation width with increased
  padding and line spacing.
- Markdown headings, paragraphs, lists, quotes, and fenced code blocks render
  as distinct readable blocks instead of a compressed text run.
- Chat follows streaming output after the final Markdown layout pass and opens
  saved conversations at the bottom.
- Downloaded models can be loaded and compile-warmed explicitly from Models,
  Server Overview, or Server Developer. Keep-alive choices include 15 minutes,
  one hour, and forever.

## LAN Serving

- Local-only `127.0.0.1` endpoints are labeled clearly.
- Authenticated LAN mode advertises the host Mac's active IPv4 address when one
  is available.
- The Developer view can enable or disable LAN access and generates OpenAI- and
  Ollama-compatible examples for the active endpoint.
- LAN mode continues to require bearer authentication and does not add TLS.
  Use it only on a trusted private network or behind an authenticated TLS proxy.

## Validation

- Native unit coverage includes the resident-load request and LAN endpoint.
- UI automation covers resident loading, LAN guidance, long Markdown streaming,
  and bottom visibility after streaming completes.
- CI now runs once for `main` and pull requests instead of duplicating checks on
  branch, merge, and release-tag pushes.

The community DMG is ad-hoc signed and is not Apple-notarized. Verify the
published SHA-256 checksum before overriding Gatekeeper.
