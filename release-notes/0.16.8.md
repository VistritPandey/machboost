# MachBoost 0.16.8

This release repairs native MLX text serving and adds an early terminal coding
agent.

## Changes

- Keeps each MLX text replica on the worker thread that loaded its tensors,
  preventing cross-thread GPU stream failures in resident serving.
- Correctly separates Gemma-style reasoning channel markers from visible text
  without treating ordinary special tokens as end-of-generation tokens.
- Adds `machboost code MODEL --workspace PATH` with bounded file, search, edit,
  delete, shell, and Git diff tools.
- Adds manual, accept-edits, plan, and bypass permission modes to terminal coding
  sessions.
- Displays reasoning and final answers as separate terminal sections and warns
  when reasoning consumes the entire output budget.
- Performs model warmup in the background by default, with explicit `sync` and
  `off` alternatives.
- Recovers from a bounded number of empty post-tool model turns instead of
  silently ending a coding request.

## Validation

- 587 Python tests pass.
- All Go package tests pass.
- A live resident Gemma 4 26B MLX test produced a complete streamed answer at
  0.58 seconds TTFT and 78.36 tokens/second after the model and kernels were warm.
- A live Muse Glimmer coding test listed, read, edited, and executed commands in
  a disposable workspace. Warm tool-turn TTFT ranged from 0.54 to 2.47 seconds
  in that run. These measurements describe one development machine and are not
  universal performance claims.

The first MLX kernel compile for a large model can still take tens of seconds.
Background warmup changes when that work happens; it does not remove the work.
