# MachBoost 0.8.0

MachBoost 0.8.0 adds a private Team Gateway to the native macOS app, Python
package, and resident inference server. One Apple Silicon Mac can now serve
several employees through scoped keys while preserving the existing local chat,
repository workspace, text, vision, and acceleration paths.

## Team Gateway

- One-time employee keys stored only as SHA-256 digests, with scopes, model
  allowlists, concurrent-request limits, requests-per-minute limits, and
  revocation.
- Tenant-fair model queues that prevent one employee's burst from blocking all
  other queued users while retaining replica affinity.
- Local SQLite/WAL traces with `off`, metadata, redacted, and full modes,
  configurable retention, and a bounded disk budget.
- Deterministic latency, time-to-first-token, completion-rate, and throughput
  evaluations, plus optional scoring by a resident local judge model.
- OpenAI- and Ollama-compatible function tool schemas and multiple returned
  tool calls. MachBoost returns requests to the calling agent and does not
  execute tools itself.
- Connection metadata for OpenAI-compatible coding agents and Ollama-compatible
  clients.

## Native App

- New Team view for issuing and revoking employee keys and copying connection
  settings.
- New Logs & evals view for trace privacy, retention, disk limits, trace
  selection, deterministic evaluation, and local-model judging.
- The bundled daemon starts Team Mode automatically and stores team data in
  MachBoost Application Support.

## CLI And Python

Start a team node with:

```sh
export MACHBOOST_API_TOKEN="your-admin-token"
machboost serve --team --host 0.0.0.0 --replicas 2
```

The Python client adds key, policy, trace, and evaluation helpers. See the
[Team Gateway guide](../docs/TEAM_GATEWAY.md)
for scopes and private-network deployment.

## Performance Contract

Team Mode improves sharing, fairness, governance, and model residency. It does
not alter MachBoost's acceleration contract and does not claim faster unique
first prompts. The recorded repository and repeated-image benchmark results
remain workload-specific; v0.8.0 introduces no new universal speed claim.

## Install

1. Download `MachBoost-0.8.0-arm64.dmg`.
2. Drag MachBoost into Applications.
3. Attempt to open MachBoost once.
4. Open **System Settings -> Privacy & Security** and choose **Open Anyway**.

This free community build is ad-hoc signed and is not Apple-notarized. Verify
the accompanying SHA-256 checksum before overriding Gatekeeper.

Requirements: Apple Silicon, macOS 14 or newer, and sufficient storage for the
application and selected Hugging Face model weights.
