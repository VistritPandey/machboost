Native control surface

Your Mac becomes the inference server.

Chat locally, keep models resident, attach persistent context, index a codebase, or serve the same runtime through familiar APIs.

  • Repository intelligence

    Keep repository access on the developer's Mac. Choose Plan, Manual, Auto, Accept edits, or Bypass while the selected-folder boundary stays enforced.

  • Resident serving

    Keep multiple models warm behind one bounded, tenant-fair gateway with cancellation, employee limits, and resource metrics.

  • Text, vision, and tools

    Run MLX and MLX-VLM models with persistent files and images. Muse Glimmer runs from native Hugging Face MLX conversions with reasoning, vision, and tool-call output.

  • Drop-in APIs

    Connect through Claude Desktop's native inference gateway, OpenAI Chat Completions and Responses, Anthropic Messages, Ollama-compatible routes, the Python client, or a named device profile whose token stays in macOS Keychain.

Team Gateway

One Mac. Your team's coding agents.

Give each employee a scoped key and point Codex, Claude Code, Cline, Kilo Code, or another compatible client at a private endpoint. The desktop app can discover several MachBoost Macs and route each new request to a compatible resident model with the best current load. Each host enforces model access, concurrency, request rates, and fair queueing between employees. Revision-aware memory can reuse validated repository knowledge without exposing private work, while exact reusable prefixes can avoid repeated prefill when requests genuinely overlap. Budgeted external providers remain an explicit fallback, with a separate provider-model mapping and recorded cost.

Architecture

Repos stay with developers. Models run across the host pool.

Client apps execute scoped repository tools locally, discover approved hosts, and select one compatible machine before generation. Each host schedules requests across its own resident native MLX models.

Repository paths and credentials are not sent as host presence metadata. Writes are applied on the client only after approval. Routing is request-level and desktop-side: an in-progress stream is not migrated, memory is not pooled across Macs, and generic API clients use the single endpoint they target.

Measured, not hand-waved

Speed where expensive work can be skipped.

MachBoost can reuse exact prefixes or reduce target decode passes on selected verified-decoding models, and it preserves model-native acceleration when serving through its gateway. It does not claim every request, model, or prompt becomes faster.

The latest native 3B audit indexed 8,843 files into 26,394 chunks and compared cache-off MLX against MachBoost with the same loaded model, weights, prompts, tokenizer, and greedy generation. Ten different repository questions were token-identical; the median reused 8,410 of 10,265 prompt tokens. The 10-client diagnostic used one safe resident replica and 20 measured requests. It improved throughput 5.06×, p50 latency 4.97×, and TTFT 5.93×, but only 16/20 output hashes matched, so it is not presented as an exact acceleration result. The earlier production-shaped repository audit used an 8,754-file private monorepo, independent standalone threads, alternating order, and the same loaded MLX model, weights, prompts, and tokenization within each pair. Private paths, prompts, and outputs are not published. Decode time did not improve. The fresh-decode row compares the same BF16 target weights at a fixed 512-token output length using the shippable runtime; prompt medians range from 1.31× to 2.43×, and its three 128-token validation prefixes match. The same-weight 9B BF16 row ranges from 1.58× to 2.42×, but its output gate found a mismatch; a faster 9B 4-bit control also diverged. Exact replay and semantic memory are separate contracts. The visual figure is the median of six model-level paired medians. Muse Glimmer now resolves to the native mlx-community/Muse-Glimmer-30B-4bit conversion through MLX-VLM. The older explicit muse-glimmer:30b-mlx Ollama adapter remains for backward compatibility.

How it works

Reuse the expensive part safely.

  1. 01

    Load once

    The resident server keeps selected MLX models in unified memory.

  2. 02

    Build stable context

    Repository maps, documents, images, and chat prefixes are organized so exact reusable regions remain identifiable. Long app chats compact older turns into durable summaries near the selected context limit.

  3. 03

    Restore model state

    Compatible MLX caches skip repeated prefill work while preserving the same target-model generation path.

  4. 04

    Retrieve what changed

    Focused evidence and the new question are evaluated normally, with citations returned to the client.

Community preview

Download. Drag. Approve once.

The preview DMG is free and ad-hoc signed. Apple has not notarized it, so macOS asks you to approve the app manually after download. Community releases from version 0.15 onward use a signed Sparkle feed for in-app download, verification, installation, and relaunch.

  1. 1

    Download the DMG

    Apple Silicon and macOS 14 or newer are required.

  2. 2

    Drag MachBoost to Applications

    The bundled runtime includes Python, MLX, MLX-LM, and MLX-VLM. Native models do not require Ollama.

  3. 3

    Attempt the first launch

    macOS will block the unidentified community build initially.

  4. 4

    Choose Open Anyway

    Go to System Settings → Privacy & Security, then approve MachBoost. Later launches open normally, and signed in-app updates do not send you back through the download page.

Use your existing tools

One local endpoint.

The app and CLI speak through the same daemon. Point Responses, Chat Completions, Anthropic Messages, or Ollama-compatible clients at MachBoost. Loopback works only on the host Mac; authenticated LAN mode displays a reachable address and token for teammates on the same private network. Claude Desktop connects through its native third-party inference gateway, not MCP, and can use models resident on this Mac or a saved team host.

OpenAI Responses 
from openai import OpenAI

client = OpenAI(
    # Same Mac. For teammates, use the LAN URL shown in Server > Developer.
    base_url="http://127.0.0.1:11435/v1",
    api_key="machboost"
)

response = client.responses.create(
    model="muse-glimmer:30b",
    input="Inspect this incident and propose the next tool call."
)
